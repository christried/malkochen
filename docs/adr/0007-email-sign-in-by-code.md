# Email sign-in by a code, not a magic link alone

Besides Google, users can sign in with their email address (grilling session, 2026-10-18). The email carries a 6-digit code as the main way in, plus a link. A magic link alone would open in the phone's browser, not in the installed app, so the user would end up signed in in the wrong place; a code is typed where the sign-in started. There are no passwords to store or reset. An email account and a Google account with the same address are the same user.
